# Живчик

Цифровой организм, который учится на опыте и подстраивается под изменения среды. Чистый браузер, без серверной части и без библиотек.

## Как он устроен

- **Чувства.** Ощущает «запах» веществ (сильнее вблизи) и градиент холода.
- **Память.** Для каждого вещества и для холода хранит одно число: насколько это хорошо или плохо.
- **Обучение.** После каждого опыта поправляет ожидание: `ожидание += 0.35 × (реальность − ожидание)`. Это правило Рескорлы–Вагнера, классическая модель обучения у животных.
- **Любопытство.** К незнакомому слегка тянет, иначе он никогда бы ничего не попробовал.
- **Жизнь и смерть.** Энергия тратится на движение и холод. На нуле существо умирает; потомок может унаследовать часть памяти.

## Запуск

Открой `index.html` в браузере. Всё.

## Хостинг

Это статический сайт. На виртуальный хостинг достаточно залить `index.html` в корень сайта (обычно папка `public_html` или `www`) через файловый менеджер панели или FTP.
