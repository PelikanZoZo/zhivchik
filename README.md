# Живчик

Цифровые агенты, которые учатся на опыте и эволюционируют. Зелёный и Красный едят синюю плесень, которая растёт после волн влажности, спасаются от хищников и рождают потомков. У каждого четыре шкалы: энергия, эмоции, сила, здоровье. Правила мира — в [CONDITIONS.md](CONDITIONS.md).

- **Зелёный** учится ассоциациями: помнит, насколько хороши плесень, хищник и сородич (правило Рескорлы–Вагнера).
- **Красный** — маленькая нейросеть с врождёнными рефлексами: учится на награде при жизни (actor-critic со следами решений) и передаёт мозг потомкам со скрещиванием и мутациями.

## Устройство

```
app.js                 точка входа для хостинга
src/server.js          сервер: мир живёт постоянно, сохраняется, досчитывает время сна
public/                страница (её же можно залить на обычный хостинг без сервера)
  sim/world.js         мир: агенты, плесень, влажность, хищники, рождение, смерть
  sim/sensors.js       органы чувств — единственное, что мозг знает о мире
  sim/brains/          мозги; новый мозг = новый файл + строчка в brains/index.js
src/store/             хранилище: MySQL на хостинге или файлы в data/ локально
tools/arena.js         прогон мира без интерфейса для сравнения мозгов
CONDITIONS.md          условия и ожидания
```

## Запуск у себя

```
npm install
npm start
```

Открой http://localhost:3000. Без базы мир хранится в папке `data/`.

Прогнать мир без интерфейса: `npm run arena -- 8` (8 часов реального времени за несколько секунд).

## Хостинг с Node.js (типичная панель «Setup Node.js App»)

1. Создай базу MySQL и пользователя в панели хостинга.
2. Загрузи проект (кроме `node_modules` и `data`) в папку приложения, например через Git или файловый менеджер.
3. В разделе Node.js создай приложение: версия Node 18 или новее, файл запуска `app.js`.
4. Скопируй `.env.example` в `.env` и впиши данные базы. Задай `ADMIN_KEY`, чтобы управлять миром мог только ты.
5. Нажми «Run NPM Install», затем перезапусти приложение.

Таблицы в базе создадутся сами. Если хостинг усыпляет приложение без посетителей, при следующем заходе сервер досчитает пропущенную жизнь (до ~4 часов, настраивается в `.env`).

## Хостинг без Node.js

Залей содержимое папки `public/` в корень сайта. Мир будет считаться в браузере каждого посетителя, без сохранения.

## Вход на сайт

Сайт закрыт логином и паролем (один пользователь). В коде хранится только отпечаток пароля scrypt, сам пароль — нигде.
Сменить пароль: `node tools/hash-password.js 'новый пароль'`, результат положить в переменную `AUTH_HASH` в панели хостинга. Логин меняется переменной `AUTH_USER`.
